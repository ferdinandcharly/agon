# Portail d'accueil — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** compte obligatoire, créé par un portail en 3 étapes (Parcours → Compte → Infos sur toi), avec avatar public et prénom/établissement privés.

**Architecture:** nouvelles colonnes de `profils` et fonctions de classement/amis qui renvoient l'avatar. Côté appli, `portail.js` (écran plein cadre, décision d'affichage au démarrage, étapes, composant avatar) branché sur `compte.js` (formulaire de connexion réutilisé, enregistrement du profil). Les tests passent par une **session simulée** pour atteindre l'appli derrière le portail.

**Tech Stack:** Postgres/Supabase (MCP `apply_migration`, `execute_sql`), JS vanilla, tests Node + Edge headless.

**Spec:** `docs/superpowers/specs/2026-11-23-portail-design.md`

## Global Constraints

- Branche `portail` ; ni push ni `subtree push` par Claude.
- Formats (identiques appli et base) : avatar `^(orange|jaune|vert|bleu|violet|rose|cyan)-(facette|etoile|note|eclair|coeur|vinyle)$` (défaut `violet-facette`) ; prénom `^[[:alpha:]][[:alpha:] '-]{0,29}$` (en JS : `^\p{L}[\p{L} '-]{0,29}$` avec le drapeau `u`) ; établissement 2 à 60 caractères, sans caractère de contrôle ni `<` `>` ; parcours `but-info-1` seul ; pseudo inchangé `^[A-Za-z0-9_-]{3,20}$`.
- Couleurs d'avatar : orange `#FF6B3D`, jaune `#FFC21A`, vert `#00C08B`, bleu `#3D5AFE`, violet `#7B4DFF`, rose `#FF5FA2`, cyan `#2FD3E0`.
- Public : pseudo, avatar. Privé : prénom, établissement, parcours — jamais renvoyés par `classement`, `classement_amis`, `mes_amis`.
- Fonctions : `security definer`, `set search_path = ''`, `authenticated` seulement ; changement de type de retour = `drop function` puis `create function`.
- CSP stricte (aucun style ni script en ligne ; couleurs par classes ou `style.setProperty`). Textes en français, espace insécable avant `: ? !`.
- Session gardée = clé `localStorage` `agon.session` (supabase-js). Livraison : `VERSION = "facettes-v33"`, `portail.js` dans `COQUILLE`.
- La page Réglages n'est **pas** modifiée (projet suivant).

## Review Focus

1. Session gardée mais expirée/refusée au démarrage : l'appli doit revenir au portail, pas rester bloquée sur l'accueil vide — lecture de code (pas de vrai jeton en test).
2. Compte connecté dont le profil existe déjà (ancien joueur) : jamais l'étape 3 — lecture de code (profil réel non simulable) ; le cas « profil inconnu hors ligne » est testé (scénario 8).
3. Prénom avec accent ou apostrophe (« Zoé », « N'Golo ») accepté ; avec chiffre refusé — tests tâches 1 et 3.
4. Pseudo pris à l'étape 3 : message, saisies gardées — lecture de code + message testé sur l'erreur simulée 23505.
5. Déconnexion depuis les réglages : retour au portail étape 1, l'accueil n'est plus atteignable — test tâche 3.

  - Hors ligne sans session : `.f-portail-horsligne` « Connecte-toi à Internet pour créer ton compte » + bouton « Réessayer » qui relance `decider()`.
