# Amis et barre d'onglets — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** demandes d'amis par pseudo exact, écran Amis (classement entre amis, notions allumées, records battus) et barre d'onglets Disco · Accueil · Amis.

**Architecture:** une table `amities` sans aucun droit direct, cinq fonctions `security definer` qui ne renvoient que pseudos et chiffres, une colonne `profils.notions_allumees`. Côté appli : `nav.js` (barre), `amis.js` (écran, sur le modèle de `classement.js`), et de petits branchements dans `app.js`, `compte.js`, `donnees.js`, `discotheque.js`, `classement.js`.

**Tech Stack:** Postgres/Supabase (migrations appliquées par l'outil MCP `apply_migration`, tests par `execute_sql`), JS vanilla, tests Node + Edge headless (`tests/navigateur.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-23-amis-design.md`

## Global Constraints

- Branche `amis` ; ni push ni `subtree push` par Claude (Ferdinand les lance).
- Fonctions : `security definer`, `set search_path = ''`, `revoke execute … from public, anon`, `grant execute … to authenticated`, exception si `auth.uid()` est nul.
- Aucun `grant` sur `public.amities` pour `anon`/`authenticated` ; RLS activée.
- Pseudo comparé par `lower(pseudo)` ; format `^[A-Za-z0-9_-]{3,20}$` (le même que `profils`).
- Limites : 20 demandes envoyées en attente, 100 amis par compte ; `notions_allumees` entre 0 et 2000.
- Parcours `but-info-1` ; record = meilleur score de tous les temps, date = première atteinte.
- CSP stricte : aucun style ni script en ligne (styles par classes ou `style.setProperty`).
- Textes en français, espace insécable (U+00A0) avant `: ? !`.
- Caches locaux propres au compte, vidés à la déconnexion et à la suppression : `agon.amis`, `agon.amis.vu`, `agon.notions.publiees`.
- Livraison : `VERSION = "facettes-v30"` dans `app/sw.js`, `nav.js` et `amis.js` ajoutés à `COQUILLE`.

- Produces: `Amis.ouvrir()`, `Amis.recharger()`, `Amis.rafraichirPastille()` (appel de `mes_amis`, au plus une fois par minute sauf ouverture de l'écran), et deux fonctions pures testables :
  - `Amis.recordsBattus(amis, monRecord: number|null, vuLe: string|null) → [{ pseudo, record, moi }]` — amis (`relation === "ami"`) avec `record > (monRecord ?? 0)` et `record_le > vuLe` (ou `vuLe` nul).
  - `Amis.compterPastille(amis, monRecord, vuLe) → number` — demandes `recue` + `recordsBattus(...).length`.
  - `Amis.rendre(etat, { horsLigne = false, date = null } = {}) → Element` où `etat = { amis: [...mes_amis], classement: [...classement_amis], periode: "semaine"|"record", monRecord, vuLe }`.
- Mon record = `lireRecordSurvie()` (app.js). `agon.amis` = `{ amis, classement: { semaine, record }, date }` ; `agon.amis.vu` = date ISO de la dernière ouverture de l'écran (écrite **après** le calcul de l'activité affichée).
